# Ченджлог

Все значимые изменения **run** (менеджера скриптов и задач) и встроенного в него
таск-раннера **tal**.

Формат следует [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование следует [SemVer](https://semver.org/lang/ru/).

[English version](changelog.md)

## [1.4.5] - 2026-09-29

Перевод проекта на актуальные версии `lc` и `tycl`. `tap` уже был на последней
Go-версии и не менялся.

### Changed

- **`lc` v1.5.8 -> v2.0.1.** Путь модуля теперь следует правилу семантического
  импортирования версий, поэтому каждый импорт фреймворка несёт суффикс `/v2`:
  `github.com/pt-main/lc/engine/core` становится
  `github.com/pt-main/lc/v2/engine/core`. Обновлено пять файлов:
  `tal/lang/lcproc.go`, `tal/lang/process.go`, `tal/lang/errFmt.go`,
  `tal/generation/generate.go` и `tal/shared/errors.go`.
- **`tycl` v1.3.8 -> v1.4.0.** В конфигурационный слой добавлен плоский пакет
  `diag`, JSON-конверт и новые команды CLI. Используемый в `run` Go-API
  (`shared.Config`, `generation.Tycl`, `format.FormatError`, `utils.OpenF`,
  `utils.WriteF`) не изменился, поэтому места вызова не трогались.

### Fixed

- **После обновления `lc` лексер tal перестал принимать аннотации
  `-- #depends`.** В `lc` v2 каждое правило сопоставляется со всем срезом рун
  с якорем в текущей позиции, поэтому `^` снова означает настоящее начало
  строки и больше не съедает перевод строки перед аннотацией. Этот перевод
  приходил отдельным токеном `CODE`, а в грамматике `block` не было правила,
  которое его поглощало, и разбор падал с ошибкой
  `expected "BLOCK", got "COMMAND" (raw: "-- #depends *.txt")`.
  Теперь `tal/lang/lcproc.go` отдаёт переводы строк отдельным токеном
  `WHITESPACE` и передаёт его в `NewParser` как игнорируемый тип, что
  восстанавливает прежний поток токенов. Поглощаются только переводы строк:
  более широкое правило `\s+` съедало бы ещё и пробелы внутри кода и
  превращало `local function` в `localfunction`.

## [1.4.0] - 2026-09-27

Управление скриптами и шаблонами, локальный режим и подкоманда `run tal`.

### Added

- **Пользовательские шаблоны-обёртки.** `run manage templ-add` регистрирует
  тело-шаблон Go `text/template` для любого расширения файла; на выходе
  получается Lua-обёртка, вызывающая исходный файл. Тела шаблонов живут в
  `templates/`, а `config.tycl` хранит только `{ext, file}`, поэтому шаблоны
  можно редактировать обычными редакторами.
- **Теги.** `run manage tag <script> <tag...>` добавляет теги, ведущий `!`
  удаляет их. `run -r --tagged="a;b"` выполняет все скрипты с любым из
  перечисленных тегов, `--parallel` запускает их параллельно, `--args`
  передаёт аргументы скриптам, а не самому `run`.
- **Параллельный запуск из Lua.** `run_script_parallel(name, ...)` стартует
  скрипт в фоновом потоке, а `wait()` дожидается их всех перед выходом из
  обёртки.
- **Локальный режим.** `run sys localmode true` переключает run на каталог
  `.run/` рядом с проектом; `--localmode` и `--globalmode` переопределяют
  режим для одного запуска.
- **Подкоманда `run tal`**, открывающая встроенный таск-раннер: `run tal
  init`, `update`, `list` и `run`.
- Расширения `.task.lua` и `.nd.task.lua` распознаются как Task Lua и
  выполняются через tal, второе - без проверки зависимостей.

### Changed

- Конфиги старых версий, где тело шаблона лежало прямо в поле `template`,
  мигрируют один раз при чтении: тело переезжает в `templates/<ext>.templ`,
  а в конфиге остаётся только `file`.

## [1.3.3] - 2026-09-12

### Added

- `run/lua.go`: Lua-API для генерируемых обёрток - `run_script`, `get_arg`,
  `get_args` и `script_path`.

### Changed

- Файл лицензии переименован из `LICENCE` в общепринятое `LICENSE`.

## [1.3.2] - 2026-09-11

### Added

- **Установка по URL** (`run/install.go`): прямые URL файлов, GitHub blob URL
  и короткая форма `github.com/user/repo@branch/path` приводятся к прямой
  загрузке, а URL на `.task.lua` выполняется как скрипт установки с
  `--args="..."`.

## [1.3.0] - 2026-09-07

### Changed

- **CLI разбит на подкоманды.** `run/handlers.go` и единственный
  `cmd/run/cli.go` превратились в `cmd/runcli/` с `cli.go` и `process.go`:
  `manage`, `sys` и путь запуска стали отдельными парсерами вместо одного
  диспетчера. Введены алиасы (`scradd`, `screm`, `tladd`, `tlrem`), чтобы
  короткие формы продолжали работать.

### Added

- `tal/lang/errFmt.go`: читаемое форматирование ошибок разбора для tal.

### Changed

- Правки рантайма tal в `tal/core/main.go` и `tal/runtime/main.go`.

## [1.2.1] - 2026-08-24

### Changed

- Бинарники из `build/` удалены из репозитория: их собирает скрипт сборки.
- Удалён `merged.md`.

## [1.2.0] - 2026-08-23

### Added

- **tal, встроенный таск-раннер.** Новое дерево `tal/` (`lang`, `generation`,
  `core`, `lua`, `runtime`, `shared`), отдельный бинарник `cmd/tal` и
  двуязычные `tal/README.md` и `tal/README-ru.md`. Задачи пишутся обычным Lua
  с аннотациями в комментариях - `-- @name` для задачи, `-- @` для главного
  блока, `-- @!` для глобального блока и `-- #depends <glob...>` для файловых
  зависимостей, - поэтому файл остаётся валидным Lua, а инкрементальность
  отслеживается по SHA256-хешам в `.tal.pack`, а не по времени изменения.
- `build.json` с описанием матрицы кросс-компиляции.

## [1.0.0] - 2026-08-20

### Added

## Типы изменений

- **Added** - новая функциональность.
- **Changed** - изменения существующей функциональности.
- **Deprecated** - функциональность, которая скоро будет удалена.
- **Removed** - удалённая функциональность.
- **Fixed** - исправления багов.
- **Security** - исправления уязвимостей.
- **Breaking** - ломающие изменения API.
